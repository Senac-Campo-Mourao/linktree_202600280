# 🌳 Clone do Linktree

Projeto desenvolvido na turma de **HTML e CSS - Criação de Websites** do **Senac PR - Campo Mourão**.

Este projeto é um clone simplificado do Linktree: uma página pessoal criada para reunir links, redes sociais, contatos e outros conteúdos importantes em um único lugar.

## 📚 Objetivo do projeto

Praticar os fundamentos da criação de websites enquanto desenvolvemos uma página com identidade visual própria.

Durante o projeto são trabalhados conceitos como:

- Estrutura semântica com **HTML5**
- Estilização com **CSS3**
- Organização de arquivos e pastas
- Uso de imagens
- Fontes externas com **Google Fonts**
- Alinhamento com **Flexbox**
- Cores e gradientes
- Layout para diferentes tamanhos de tela

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Você também pode utilizar a extensão **Live Server** no Visual Studio Code para visualizar o projeto com atualização automática.

## 🎨 Personalização

Este projeto pode ser personalizado alterando:

- Nome e descrição no arquivo `index.html`
- Foto de perfil na pasta `img`
- Cores e gradiente no arquivo `styles/style.css`
- Família de fonte
- Conteúdo e links exibidos na página
